# 零件库受控词表

技能 A 写入、技能 B 检索时必须使用下列枚举。禁止用近义词替换。

## shot（运镜）

| 值 | 含义 |
|---|---|
| 拉升 | 机位升高、逐渐露出环境 |
| 环绕 | 绕主体旋转 / orbit |
| 横移 | 左右平移，高度大致不变 |
| 俯冲 | 向前或向下加速接近 |
| 悬停 | 机位基本不动 |
| 未定 | 看了抽帧仍无法归类 |

## light（光线）

`日出` `日落` `晴` `阴` `夜景` `黄金时刻` `未定`

## quality

候选判定有三种结果：

- `可用`：默认截取并允许入库
- `勉强`：保留在候选清单，但默认不截取；只有用户明确要求包含时才截取并入库
- `废片`：不截取，不得写入 `library.json`

因此，`library.json` 的 `quality` 只允许 `可用` 或经用户明确纳入的 `勉强`。

## phase（长运镜阶段，可选）

`起势` `发展` `高潮` `收束`

- 同一连续运镜的零件使用相同 `motion_group`
- `phase` 描述该零件在长运镜里的阶段
- 不得因为主体相同就把不同阶段判为重复

## subject / move / note

- `subject`：短名词，如 `海岸线` `山脊` `村庄` `湖面`
- `move`：方向补语，如 `由低到高` `顺时针` `从左到右`
- `note`：不超过 40 字，只写画面里有的东西
